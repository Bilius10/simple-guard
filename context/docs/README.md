# Documentacao do SimpleGuard

Indice dos documentos de planejamento do projeto.

## Estrutura

- `contexto/`: contexto mestre para agentes, decisoes e guardrails do projeto.
- `discovery/`: descoberta de produto, proposta de valor, ICP e lacunas.
- `produto/`: brief, PRD e artefatos de produto.
- `ux/`: especificacoes de experiencia para plataforma web e agentes.
- `arquitetura/`: arquitetura tecnica, decisoes e spine de implementacao.
- `tasks/`: tasks separadas por epico, com um arquivo por task e `central.md` por epico.
- `pesquisa/`: pesquisas tecnicas, regulatorias, operacionais e de mercado.
- `runbooks/`: sequencias operacionais para conduzir fluxos BMAD.
