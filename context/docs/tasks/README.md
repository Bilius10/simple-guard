# Tasks do SimpleGuard

Esta pasta organiza as tasks derivadas dos epicos do SimpleGuard.

Estrutura:

- Uma subpasta por epico.
- Cada subpasta contem um `central.md` com a descricao do epico.
- Cada story/task possui um arquivo `.md` proprio.

Fonte consolidada:
- `.codex/bmad/output/planning-artifacts/epics.md`

Rastreabilidade:
- `coverage-matrix.md`

Regras:

- Tasks de front devem referenciar o UX spec da superficie e o Figma oficial.
- Tasks de front, back e agente devem incluir testes unitarios.
- Toda task deve incluir cenario de validacao manual.
- Tasks devem permanecer em tamanho medio e por capacidade testavel.
